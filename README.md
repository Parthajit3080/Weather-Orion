# Weather Orion  
*Forecasting Tomorrow, Today.*

A modern and lightweight **Weather Web App** built with **HTML, CSS, and JavaScript**, powered by the **[WeatherAPI](https://www.weatherapi.com/).**  
Weather Orion delivers real‑time weather information through a clean, responsive, and intuitive interface.

---

### ✨ Features
- Search weather by **city name** or **latitude/longitude**
- View detailed data: **temperature, conditions, humidity, wind, pressure, UV index**, and more
- Default weather cards for *Kolkata, New Delhi, and New York* on initial load
- **Responsive design** for seamless use across desktop and mobile devices
- Lightweight and fast performance with efficient API integration
